Mobile-app market-intelligence provider exposing a public REST API for App Store (iOS) and Google Play data, including app metadata, reviews, rankings, download/revenue estimates, developer lookup, keyword suggestions, and LiveOps events. Covers 13 million apps across 100 countries.

**Areas:** Mobile App · App Store Optimization · Market Intelligence · App Analytics · Google Play · apple-app-store · Reviews and Ratings · download-revenue-estimates · Marketing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for AppstoreSpy: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
